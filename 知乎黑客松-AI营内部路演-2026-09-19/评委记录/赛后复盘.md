# 知乎黑客松 · AI营内部路演 · 赛后复盘

> 质检环节：**这批货的尺子有没有走偏。**
> 本场特殊：**打了两遍**。v1 用备用 rubric（未拿到规则），v2 用主办方规则。所以本次复盘多了一条——
> **不只检查我打得准不准，还要检查我"用错尺子"这件事本身。**

## 0 · 本场最该记住的一课：我用错过一次尺子

CJY 第一次发材料时没给评分规则，我按 SOP 走了"主办方未提供 → 用备用 rubric"这条路。
第二天他补了规则截图，两套尺子差别很大：

| | 备用 rubric（v1） | **主办方规则（v2）** |
|---|---|---|
| AI 深度 | 藏在"创新与 AI native"里，20% | **独立为"AI 场景价值"，35%** |
| 创新 | 和 AI 深度混在一起 | **独立，25%，只问"场景想象力 + 玩法新颖"** |
| 商业化 / 谁付钱 | **"价值与收口"15%** | **不存在** |
| 设计感 | 无 | **8%** |
| 团队 | 5% | 无 |
| 赛制要求 | 无 | **"以 Demo 实操演示为主"明文写死** |

**我犯的两个错：**

1. **自设了主办方没有的封顶条款**（"AI 黑客松无 AI → 创新维度封顶 7"）。
   我把 AI 深度塞进了创新维度——而官方规则里这两件事是**分开的两个维度**。
   结果：共读伙伴的创新度被我压到 7/20，而按官方尺子它该拿 85/100（全场第二）。
   → **备用 rubric 里的自定义条款，是"我的附加判断"，不是尺子本身。以后要标清楚。**

2. **把"谁付钱"当成 15% 的大项扣。** 官方规则里根本没有商业化维度。
   我给知径、知路扣的那几刀，**在真尺子下一分都不该扣**。
   → 最讽刺的是：**这正是我自己的盲点 #6（识别不了客户）在作祟。
   我对"谁付钱"太敏感，敏感到把它加进了别人的考卷。**
   「万事万物相互联系」的一个难看的形态：**我最会诊断的病，也最容易被我误诊到别人身上。**

**已落实的改法**（写进 `SOP.md` 与 `docs/评委风格-CJY.md`）：
- 接料阶段，**"有没有评分规则"要问到明确的是或否**，不能默认"没给 = 用备用"就往下走。
- 用备用 rubric 时，**在评分表首行加一句"本场规则未到位，分数可能随规则到位而整体重排"**，
  而不是等规则来了再返工。
- **备用 rubric 里我自己加的硬条款（封顶、一票否决）要单独标注为"CJY 附加"**，与主办方条款区分。

## 2 · 我和其他评委差在哪

**待回填**。我预判最大的三处分歧：

1. **知识星图的 AI 场景价值 = 66。** 这一刀砍在我的判据上（"把 AI 抠掉它还成不成立"），
   而规则原文只写"是否构建了**有意义的** AI 场景"。**"有意义"怎么读，是本场最大的解释空间。**
   按"有没有用到 AI"来读，它能到 80，总分 77，仍是第 2 —— **名次不变，但分差会从 13.4 缩到 8.9。**

   会让人不舒服。但规则里创新度只问"场景想象力 + 玩法新颖"，**它确实答得最好之一。**
   我认为按规则打就该给，这是尺子的纪律。
3. **退租审判 vs 知路（61.30 : 61.14）。** 差 0.16 分，**这是并列，谁在前都合理。**

## 3 · 我自己学到什么

1. **"核心链路免费，付费发生在持续与高频的使用价值被验证之后"（知域）** ——
   这句话直接回答了我卡了很久的定价问题。不是把价定高，是**把价放到价值被验证之后**。
   这是我 patterns 盲点 #1「系统性低估价值」的新解法。
2. **"免费版用本地内置模型 / 付费版外接模型厂商"（知恋森林）** ——
   **把付费墙划在算力上**，可以直接搬进我的青少年 AI 课。
3. **"我们不解决完全不想学的问题"（知径·瑾涣）** —— 敢说"我不做什么"，是我盲点 #2「战线过多」的解药。
4. **"让用户在真正吃亏之前，先在游戏里经历一次"（退租审判）** ——
   招生话术：**让孩子在真正被 AI 取代之前，先做一次 AI 的主人。**
5. **"模拟环境下没有外界压迫，所以人敢迈第一步"（共读伙伴）** —— 孩子不敢提问不是不会，是怕说错。
6. **（本场新增）评委最大的风险不是打偏，是用错尺子。** 打偏能靠校准修，用错尺子会让整张表作废。
