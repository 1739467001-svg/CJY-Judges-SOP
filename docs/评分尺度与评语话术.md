# 评分尺度与评语话术

> 解决两个老毛病：**分数全挤在 85 附近**、**评语全是"很有潜力，继续加油"**。

---

## 一、分数锚点（百分制）

先给**维度分**，让总分自己长出来。不许先定名次再倒推分数。

| 区间 | 定性 | 长什么样 |
|---|---|---|
| **95–100** | 全场标杆 | 换个场子也能拿奖；现在就有人在用；我会主动想认识这支队 |
| **85–94** | 明确获奖档 | 跑得起来 + 想法站得住 + 讲得清；短板是"还没做到"，不是"做错了" |
| **75–84** | 中上，合格完成 | 东西成立，但有一处明显塌陷（没部署 / 场景空 / 讲不清 / AI 是贴的） |
| **65–74** | 及格线附近 | 有一个能看的点，其余靠讲；离"能用"还隔着一层 |
| **50–64** | 不完整 | 只有 PPT，或者功能没跑通，或者答非所问 |
| **<50** | 不成立 | 跑题、套模板、明显是别处搬来的 |

**校准动作**：全场均分应落在 **70–80**。
高于 80 → 尺子松了，回去拉差距；低于 65 → 要么这场确实弱（在复盘里写明），要么我今天太苛刻。

### 一票否决 / 强制扣分（在 `评分规则.md` 里按本场情况确认）
- **只有 PPT、没有可运行的东西** → 技术与完成度维度不超过及格线。
- **拿现成开源项目换个皮当原创** → 创新维度清零，并在手记里记明。
- **演示造假**（录屏当实时、写死返回冒充模型输出）→ 直接标注，交主办方处理。
- **跑题**（没有回应本场赛题/赛道）→ 总分按规则封顶。

## 二、评语结构（五段式）

> 长度控制在 **250–400 字**。评语不是越长越显得用心，**是越准越显得用心**。

```
① 一句话定位     —— 我怎么理解你们做的这个东西（也是在验证"你讲清楚了吗"）
② 亮点 2–3 条    —— 具体到可指认的地方，并说明"这部分为什么能放大"
③ 瓶颈 2–3 条    —— 说透，但说的是"卡在哪"，不是"你不行"
④ 下一步 1–3 件  —— 48 小时内能动手的，不是"建议加强商业模式思考"
⑤ 一句比喻       —— 让他们真的"感觉到"问题在哪
```

### 例（骨架示范，不是真实项目）

> **①** 你们做的是一个"把课堂录音自动变成家长周报"的工具，用户是老师，掏钱的大概率是学校。
> **②** 亮点：转写到成稿是真跑通的，现场换了段音频还能出结果，这在今天全场是少数；
> 周报模板做了分年龄段，说明真的去看过家长在乎什么。
> **③** 瓶颈：一是没有部署，评委点开链接是打不开的，"能跑"目前只存在于你们的电脑上；
> 二是掏钱的人（学校/家长）和使用的人（老师）不是同一个人，这条链你们路演里没提。
> **④** 下一步：①今晚先挂上线，给出一个别人能点开的地址；②找 3 位真老师录一段真课，
> 把"能跑"变成"有人用过"；③把"给学校省了多少老师工时"算成一个数字。
> **⑤** 你们现在手里是一台调好的发动机，但还没装上车轮——**能轰鸣，还不能载人。**

## 三、禁用话术（说了等于没说）

| ❌ 别写 | ✅ 改成 |
|---|---|
| 很有潜力，继续加油 | 潜力具体在哪一块、要动什么才能兑现 |
| 技术实现较为扎实 | 哪个模块扎实、你从哪看出来的（换输入还稳 / 有错误处理 / 部署了） |
| 建议加强商业模式思考 | 谁付钱、付多少、凭什么——挑一条让他们下周就去验证 |
| 创新性不足 | 这个做法市面上已有 X，你们和它的差别是 Y，Y 目前还不够成为理由 |
| 演示效果不错 | 演示里最让我信的是哪一下；以及哪一下我不信、为什么 |
| 团队配合默契 | 分工是什么、互补在哪；或者直说三个人在干同一件事 |

## 四、写"劣势"的姿态

三条原则（骨子里的东西：**把人当人**）：

1. **对事不对人**——"这个功能没跑通"不是"你们技术不行"。
2. **给得起的才说**——指出的每条短板，后面都得跟一条他们做得到的动作。
3. **不替他们决定放弃**——我说"这条路我认为走不通"，同时说清**我的依据**，让他们自己判断。

> 对照「付费 ≠ 体验」：
> 一句"这是很好的锻炼"经常被用来抵掉本该给的钱；
> 同样地，一句"很有潜力"经常被用来抵掉本该给的**真话**。
> **我给分、给评语，就是给选手的报酬，不能打折。**
