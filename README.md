> 陈俊烨（CJY）以 **评委 / 导师 / 指引者** 身份看项目时，一次次打分、点评、复盘的沉淀地。
> 配套的个人画像在另一个库 [`myself`](https://github.com/1739467001-svg/myself)（代号「织」），
> 本库是「织」的一条外延：**把"我怎么看一个项目"这件事也织进来。**

一句话定位：**`myself` 记录"我是谁"，本库记录"我怎么判断别人"。**

## 目录规范（硬约定）

主目录下，**一场比赛一个次目录**，命名为 `比赛名称-比赛时间`：

```
CJY-Judges-SOP/
├── README.md                         ← 本文件：规范 + 全部比赛索引
├── CLAUDE.md                         ← 给 Claude 的作业说明（每次开工自动读）
├── SOP.md                            ← 评委标准作业流程：从收到材料到产出评语
├── docs/
│   ├── 评委风格-CJY.md                ← 我的评委人格：我用哪几把尺子看项目
│   ├── 评分尺度与评语话术.md            ← 分数锚点 + 评语结构 + 反"好好先生"
│   └── 通用评分规则-备用.md            ← 主办方没给规则时的兜底 rubric
├── templates/
│   └── _比赛名称-YYYY-MM-DD/          ← 整个文件夹复制一份改名即可开新赛
│
├── 浙工商AI应用创新大赛-2026-01-08/     ← 示意：真实比赛长这样
├── 汤泉黑客松太原站-2026-02-07~08/
└── ...
```

**命名规则**

| 情况 | 写法 | 例子 |
|---|---|---|
| 单日 | `比赛名称-YYYY-MM-DD` | `小红书黑客松巅峰赛-2026-04-09` |
| 跨日（同月） | `比赛名称-YYYY-MM-DD~DD` | `上海黑客松lessismore-2026-01-23~25` |
| 跨月/跨年 | `比赛名称-YYYY-MM-DD~YYYY-MM-DD` | `某赛-2026-12-30~2027-01-02` |
| 同一赛事多赛段 | 名称里带赛段 | `高校联盟Tour浙大复赛-2026-03-07~08` |

- 比赛名称用**中文简称**，去掉"第X届""大赛"等冗余，能一眼认出即可；不加空格，用连字符断开。
- 时间取 **路演/评审当天**（不是报名日）。

## 每个比赛次目录下放什么

```
<比赛名称>-<时间>/
├── README.md            ← 本场索引：赛事信息、我的角色、最终排名、一句话结论
├── 评分规则.md           ← 主办方规则原文/整理 + 我的权重细则（本场唯一的尺子）
├── 评分详情/
│   ├── 总榜.md           ← 所有选手逐维度分数 + 排名 + 分差说明
│   └── 01-队伍名.md      ← 一队一份：作品信息 / 逐维度打分 / 优势 / 劣势 / 评语 / 下一步
└── 评委记录/
    ├── 路演原始材料.md    ← 你发我的文字总结或录音转写（原样存档，不改）
    ├── 评委手记.md        ← 现场观察、我问了什么、临场改分的理由
    └── 赛后复盘.md        ← 这场我的尺子准不准、下次改什么
```

> 要求 1「比赛名称 + 比赛时间」→ 次目录名。
> 要求 2「评分详情 + 评委记录」→ 次目录下的两个文件夹，缺一不可。

## 怎么用（给我自己看）

1. 我把 **路演文字总结 / 录音转写** + **选手作品信息** + **本场评分规则文档** 发给 Claude。
2. Claude 按 [`SOP.md`](SOP.md) 走：建目录 → 存原始材料 → 逐队打分 → 出总榜 → 写复盘。
3. 我看分、改分、补评语；Claude 把改动同步回文件，并更新上面的索引表。
4. 攒够几场后做一次**尺度校准**：同样的项目，我在第 1 场和第 5 场会打出一样的分吗？
