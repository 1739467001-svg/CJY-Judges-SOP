# 模板使用说明

新开一场比赛，**复制整个文件夹再改名**，不要一个一个新建文件：

```bash
cp -r "templates/_比赛名称-YYYY-MM-DD" "浙工商AI应用创新大赛-2026-01-08"
```

然后：
1. 改 `README.md` 抬头的赛事信息
2. 把主办方规则填进 `评分规则.md`
3. 路演材料原样贴进 `评委记录/路演原始材料.md`
4. `评分详情/01-队伍名.md` 按队伍数复制多份，序号从 01 起，按**路演顺序**编号（不是名次）
5. 评完更新根目录 `README.md` 的比赛索引表

> 模板里的 `<尖括号>` 是待填占位符，`（）` 里是写作提示，交付前都要清掉。
> 信息缺失一律写 **「待确认」**，不许脑补。
